# Student Performance Dashboard

## About the Project
This project is an interactive dashboard that analyzes student academic performance using Python, Streamlit, Pandas, and Plotly.

## Features
- Total student count
- Average final grade
- Pass and fail statistics
- Pass percentage
- School and gender filters
- Interactive charts
- Student dataset preview
- Download filtered dataset

## Technologies Used
- Python
- Streamlit
- Pandas
- Plotly
- CSV Dataset

## Dataset
Student performance dataset containing academic grades and student information.

## Project Structure
- app.py – Main dashboard application
- requirements.txt – Required Python libraries
- student-mat.csv – Dataset
- README.md – Project documentation
